Diagnosing a failed LLaVA training run

While fine-tuning LLaVA-1.5 7B with LoRA, the loss suddenly rose and training failed.

Details
  • Found in the W&B training logs that the loss rose while the learning rate stayed at its peak.

Public facility siting module (government project)

The data was small with many missing values. So instead of recommending locations directly, I treated it as a regression problem that predicts expected usage for each candidate site.

  1. Population data
  2. Add bus boarding data
  3. MAPE down 20%p
Details
  • Areas with high usage for their population turned out to be office districts. Adding floating population from bus boarding data lowered MAPE by 20%p.
  • Assumed a facility was built at the first candidate, recalculated demand, and repeated, so recommendations did not cluster in one place.
  • Built an API that shows recommended sites on a map and delivered it with a report.
